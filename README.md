# P.H.Tools — Exact-style Kurdish Sorani Store

This package recreates the supplied P.H.Tools website mockup as a functional responsive front-end.

Included:
- Kurdish Sorani RTL interface
- Rabar_037 font supplied by you
- P.H.Tools logo
- 3:5 construction hero artwork
- Dark header + search + account/wishlist/cart controls
- Red/black navigation
- Trust/feature strip
- Category cards
- 6-column desktop product grid
- Brand strip
- About/contact/footer sections
- Functional search, category filtering, cart, quantities and localStorage
- Mobile responsive layout

Open `index.html` to run it.

Replace placeholder contact information in `index.html` before publishing.
The checkout is a front-end demo; real payments/orders require a backend.
